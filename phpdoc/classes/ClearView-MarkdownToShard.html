MarkdownToShard — recursive descent markdown parser.

Converts markdown text directly to Shard-compatible arrays, skipping the HTML intermediate step entirely. No jsonmangler, no fromhtml(), no ProcessWire dependency.

Output shape: {glyph: 'h1', value: 'Title'} {glyph: 'p', children: [{glyph: 'text', value: 'Hello'}]} {glyph: 'ul', children: [{glyph: 'li', children: [...]}]}

Wikilinks [[path|label]] → {glyph: 'a', href: 'path', value: 'label'}
