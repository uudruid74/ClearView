MosaicBrowser.php : 20

Mosaic Browser — CLI REPL for exploring panes without a web browser.

Two modes: dummy (default) — test views + null crystals, zero dependencies real — vendor/site crystals, requires ProcessWire

Usage: php bin/mosaic-browser --view=test-login php bin/mosaic-browser --pane=loginform --inlay=login --method=open php bin/mosaic-browser --view=test-login --dump php bin/mosaic-browser --mode=real --url=/loginform/login/
