Controller for managing the Tor network.

The Skeksi controller issues commands to the Tor network, such as querying network status, sending signals, or managing circuits. It leverages the Stem interface to interact with Tor’s control protocol.

Why: Enables high-level control of the Tor network within ClearView’s framework.
