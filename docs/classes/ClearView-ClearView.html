loadView()

public static loadView(string $view[, array<string|int, mixed>|null $params = null ][, string|null $from = null ]) : Shard

This function uses a Facet object to record the output of the specified view, then passes that output to Shard::loadShard() to create a structured Shard object. The inlay name is set to '__$view' to prevent storing transient data in the client's Mosaic, ensuring it remains local to the page generation process. It is used to represent the view's content in a format that can be manipulated or rendered within the ClearView framework.
