Mosaic.php : 26

Request-scoped store for Shards, owned by the current Pane.

Shards are indexed by inlay-id, deflated into hidden inputs on the client, and re-inflated on every request. The Mosaic instance represents the current request's single client Mosaic — not a global aggregate of all panes.

Each Pane owns its Mosaic via $this->mosaic = new Mosaic(). Access the current instance via ClearView::Mosaic().
