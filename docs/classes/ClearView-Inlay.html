Inlay.php : 21

Subclass of Pane used when the URL includes an inlay segment.

An inlay represents a tab/subpage inside a pane. The default html() method renders Page::body and fires inlaychange when the inlay differs from $this['Shared::prevInlay'].

Inlay subclasses live under modules//panes//.php with class names like ClearView<panename>_.
