ClearView Testing Framework Architecture

Runner lifecycle, CLI surface, and integration seams

CLI Surface

  • • Single entry point: utility/clearview-test.php
  • • Reuses phpunit.phar engine under the hood
  • • Supports --filter, --suite, --ci, --base-url

Test Layers

  • • Unit: Element / Shard / Mosaic isolation
  • • Integration: ViewBuilder + InlayStub dispatch
  • • Smoke: ServerHarness against live server

Safety Rules

  • • Reset singletons between tests, never remove them
  • • InlayRegistry consulted only when inTesting()
  • • Smoke tests self-skip when no base URL
