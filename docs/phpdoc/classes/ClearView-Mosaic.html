Mosaic.php : 25

Manages a collection of Shards, handling storage, retrieval, and manipulation of variables and elements.

The Mosaic class is a singleton that serves as the central storage for Shards in ClearView, organizing them by inlay and ID to form a structured data model. It provides methods for adding, retrieving, updating, and deleting Shards, as well as searching and rendering them as HTML inputs for client-side synchronization via HTMX. Mosaic interacts with Facet for template expansion, Shard for data encapsulation, and Crystal for ProcessWire API access. It supports variable watching, sanitizers, and field searches, and tracks changes for efficient updates.
