ServerHarness
in package

ServerHarness.php : 20

Curl-based HTTP smoke-test helper for ClearView.

Preferred transport is PHP's curl_* extension. Falls back to a shell curl subprocess when the extension is unavailable. Throws TestHarnessException when neither curl transport is usable.

Usage: $server = ServerHarness::at('http://clearview.local')->asHtmx(); $resp = $server->get('/form/login/open/'); assert($resp->status() === 200); assert(str_contains($resp->body(), '<form'));
