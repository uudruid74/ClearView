Class for managing page data in ProcessWire.

Build a module search stack: Config::MODULES_LIST base + ProcessWire page hierarchy modules.

public static buildModuleStack() : array<string|int, string>

Starts with the base module list from Config::MODULES_LIST (site, vendor), then walks up the ProcessWire page tree collecting modules field values. Page modules are inserted after 'site' so site always has priority. 'vendor' is always the terminal fallback.
