QueryParser.php : 19

Handles parsing and interpretation of variable query expressions.

This class centralizes all logic for understanding and resolving template expressions used by Facet. It parses expressions into components and resolves them against the current application state, handling method calls, variable lookups, and HTML/CSS attribute definitions.
