ClearView.php : 24

Singleton controller for the ClearView framework.

Created by ClearView::Init($template) once per request. Owns the JavaScript/async/OOB/debug buffers, resolves URL components, loads Pane/Inlay classes from the module stack, and exposes static helpers for scripts, HTMX detection, and cross-inlay dispatch.
