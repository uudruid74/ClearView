Pane.php : 25

Crystal for the pane page in ProcessWire.

Wraps the ProcessWire page associated with the current pane URL. After Crystal::plugAllCrystals() creates it with a null page, ClearView::init() replaces it with the correct ProcessWire page.

Field access (Pane::name, Pane::title, etc.) delegates to the ProcessWire page. Unknown keys fall back to raw Mosaic shards under the "Pane" inlay so that transient values (e.g. Pane::Key as a CSRF token from URL parameters) continue to work.
